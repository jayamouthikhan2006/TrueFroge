2. Starting point

From scratch. No editor-agent project was forked, so there is no upstream loop to replace and no fork commit to declare. The extension uses native VS Code APIs (CodeLensProvider, decorations, TextDocumentContentProvider, a webview view). Third-party code is limited to libraries: @truefoundry/trueforge-sdk 0.185.0, @modelcontextprotocol/sdk 1.32.2, diff 9, express 5, zod 4, yaml 2. Licence: MIT.

3. Architecture on TrueForge

Client of a TrueForge agent. Every prompt becomes a turn on a TrueForge session (POST /sessions/{id}/turns, SSE, via the TypeScript SDK) created from the forge-coding-agent definition in trueforge-config/; the extension renders the streamed events and never calls a model. TrueForge runs locally (npx @truefoundry/trueforge@latest, SQLite); scripts/setup-trueforge.sh starts it and registers models, MCP server, skills and agent.

Editor capabilities as MCP tools. The extension embeds an MCP server (Streamable HTTP 127.0.0.1:8791/mcp, bearer token) exposing retrieve_context, search_symbols, read_file_range, list_directory, load_skill, propose_edit and run_terminal_command; the agent decides what to read, change and run.

Approvals drive the diff review. propose_edit never writes. When TrueForge pauses for its approval, ForgeCode applies the search/replace edits in memory and renders red/green hunks with ✓ Accept Hunk · ✗ Reject Hunk · ✓ Accept All in File · ✗ Reject File CodeLenses. Once every hunk is decided it takes an undo snapshot, writes the accepted hunks byte-exact and answers allow (or deny with a reason). Stop (Esc) discards staged hunks, aborts the stream and process tree, calls POST /sessions/{id}/cancel (the paused tool never runs) and checks git status. Failover: a [Model Error] on connection refused, 401/403/404/408/429/5xx or a 120 s silent watchdog PATCHes the same session to the fallback model and re-dispatches the turn.

4. How context is selected

A workspace index (212 files, 1,539 chunks of Flask, built in under a second, refreshed by file watchers) chunks Python by symbol (decorators incl. multi-line @click.option stacks, signatures, docstrings, methods) and rst/Markdown by section. retrieve_context scores each chunk 0.5·symbol match + 0.3·BM25 + 0.2·path proximity: head-clause terms count double, a decorator-exemplar signal (@click.command for "add a CLI command"), verbatim identifiers, and a reference signal that finds registration sites (FlaskGroup.__init__ → add_command(...)). Deliverable words ("covered by a test", "documented") drive facets: the packer reserves a leader for source, test and docs chosen by affinity (cli.py ↔ test_cli.py ↔ cli.rst), then packs greedily into a token budget (default 6,000; the agent may raise it), falling back to signatures for chunks over 20% of the budget or files over 40%. @file/@symbol mentions are resolved with VS Code's symbol providers and counted against the same budget. Every call returns a ContextManifest (files considered vs. selected, score components, a reason per file, tokens used) to the model and to the panel's budget meter; in the recorded Task B it selected 8 files led by cli.py, cli.rst, app.py and test_cli.py at 5,990 / 6,000 tokens.

8. Known limitations and what we would do with another month

  • With Nemotron 3 Ultra the recorded Task B took ≈ 14 min wall-clock (model latency and its own test iterations); the video fast-forwards model waits and plays Task B at 1.6×. Task A/Stop, Task B and Task C are three separate continuous takes.
  • TrueForge 0.185 drops Gemini 3.x thought signatures; we ship a small gateway instead of patching the harness.
  • Native skills need a sandbox (macOS/Linux); on Windows they go through load_skill.
  • The Python extractor is indentation/regex based; token counts are estimates.
  • Single-root workspace, one run at a time; failover re-dispatches the whole turn; typing in a file under review withdraws its hunks.
  • Upstream the thought-signature fix to TrueForge (a natural Round 2 PR).
  • Tree-sitter + LSP reference graphs; a per-model tokenizer; embeddings as a fourth signal, tuned on a labelled Flask query set.
  • Allow-for-session approval policies and merging manual edits into pending hunks.
  • Mid-turn failover that resumes from the last completed tool call.
  • CI on Linux running the end-to-end suite and native skills in TrueForge's sandbox.
